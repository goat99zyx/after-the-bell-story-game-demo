# 港湾急送 / Harbor Dispatch

Original isometric driving-and-delivery game. Open index.html in a modern browser; no installation, CDN or external assets needed. Chinese / English UI. Touch joystick or WASD / arrows. Space brakes, Shift boosts, P pauses, R recovers at a five-second cost. Stop in a glowing depot/destination for 0.8 seconds to load/unload. Six deliveries complete a shift. Cargo condition and remaining time affect score. Earned credits unlock only cosmetic vans; they are not money.

## Platforms
- Web/GitHub Pages: publish index.html, core.js, render.js, browser.js together.
- itch.io: upload the HTML5 ZIP, select play in browser, use fullscreen and mobile support. Web donations are optional; no revenue claimed.
- WeChat: import wechat/ into the official WeChat developer tools, set your own Mini Game AppID. This is a shared-runtime adaptation scaffold, NOT a submitted or device-certified release. Test touch, safe areas, rendering, storage and lifecycle on Android/iOS before release. It has no ads, purchases, analytics or remote calls. Account eligibility, platform review and monetization approval have not been verified.
